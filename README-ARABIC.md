# ملخص المشروع — نظام اللوحات الإعلانية الرقمية الرأسية (بالعربية)

---

## ما هو المشروع؟

نظام إعلاني رقمي (Digital Signage) يعمل في الوقت الحقيقي، مصمم بشكل خاص لشاشات رأسية بنسبة 9:16 (مثل 1080×1920 بكسل). يدعم تشغيل الفيديوهات والصور معاً، ويحدث المحتوى فوراً عبر WebSockets بدون إعادة تحميل الصفحة.

---

## المكونات الرئيسية

### 1. صفحة العرض (`/display`)
- شاشة كاملة (`w-screen h-screen`) بدون أي حواف سوداء.
- تعرض المحتوى مباشرة من قاعدة البيانات (`media_url`).
- إذا كان الملف فيديو (`video/mp4`, `.webm`, `.mov`) → يعرض عنصر `<video>` مع تشغيل تلقائي (`autoplay` + `loop` + `muted`).
- إذا كان الملف صورة (`.jpg`, `.png`, `.webp`) → يعرض عنصر `<img>` مع تغطية كاملة (`object-cover`).
- يستمع للتغييرات في الوقت الحقيقي عبر `supabase-js realtime` ويبدل المحتوى فوراً.

### 2. لوحة التحكم الإدارية (`/admin`)
- رفع الملفات مباشرة إلى تخزين Supabase (`signage-assets`).
- تحديد نوع الملف تلقائياً من `mime_type` (`video` أو `image`).
- معاينة مباشرة بإطار رأسي (9:16) قبل الإرسال.
- عند الضغط على "Broadcast" → يرفع الملف ويحدث قاعدة البيانات، وكل الشاشات المتصلة تستقبل التحديث فوراً عبر WebSocket.

## التقنيات المستخدمة

| المكون | التقنية |
|---|---|
| الواجهة الأمامية | Next.js 14 + TypeScript + Tailwind CSS |
| قاعدة البيانات | Supabase PostgreSQL |
| التخزين | Supabase Storage (`signage-assets`) |
| المزامنة الفورية | Supabase Realtime (WebSockets) |
| الاستضافة | Vercel (مجاناً عبر GitHub) |

---

## قاعدة البيانات (`public.active_signage_state`)

تحتوي على صف واحد يُحدث باستمرار:
- `display_slot`: معرف الشاشة (`primary_portrait`).
- `media_url`: رابط الملف العام.
- `media_type`: `video` أو `image`.
- `media_name`: اسم الملف.
- `updated_at`: وقت آخر تحديث.

---

## كيف يعمل التزامن الفوري؟

1. المستخدم يرفع ملفاً من `/admin`.
2. الملف يُخزن في `signage-assets` ويُولد رابط عام (`publicUrl`).
3. يُحدث الصف في قاعدة البيانات (`UPDATE`).
4. جميع صفحات `/display` المتصلة تستقبل إشعاراً فورياً عبر قناة `postgres_changes`.
5. الصفحة تُحدّث `mediaState` وتُعيد تحميل الفيديو أو تبدّل الصورة بدون أي `refresh` للصفحة.

## خطوات التشغيل

```bash
# تثبيت المكتبات
npm install

# إعداد البيئة (.env.local)
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...

# تشغيل محلي
npm run dev
```

- عرض الشاشة: `http://localhost:3000/display`
- لوحة التحكم: `http://localhost:3000/admin`

## ملاحظات أمنية

- سياسة `Row Level Security (RLS)` مفعّلة.
- القراءة عامة (`SELECT using (true)`) لتسمح للشاشات بالوصول.
- الكتابة مفتوحة حالياً (`UPDATE/INSERT using (true)`) — يُنصح بتقييدها لمستخدمين مسجلين في بيئة الإنتاج.
